# DocBridge

面向技术文档的 AI 翻译扩展。以双语对照方式在原文下方插入译文，代码块、命令行参数与超链接保持原样。

常规网页翻译工具处理技术文档时普遍存在代码被破坏、链接失效、页面布局紊乱等问题。DocBridge 不替换原始 DOM，仅以 `appendChild` 追加译文节点，原文结构、样式与事件绑定完全不受影响。

## 特性

- **双语对照**：原文保留，译文以左侧蓝色边框标注追加于下方，三种显示模式一键切换
- **代码块过滤**：`<pre><code>` 整棵子树跳过翻译管线，源码零干扰
- **行内标识符保护**：`<code>--pipeline_type LM</code>` 等命令参数经由占位符协议原样保留于译文对应位置
- **链接完整性**：`<a>` 元素通过 DOM 深克隆重建，`href` 与所有属性保留，链接始终可点击
- **智能句子合并**：被行内元素中断的句子自动归并为同一翻译单元，避免语义割裂
- **SPA 增量翻译**：`MutationObserver` 监测 DOM 变动，动态加载内容自动翻译
- **本地缓存**：IndexedDB 持久化翻译结果，已访问页面即时呈现
- **进度指示**：页面底部固定进度条，完成后自动消失

## 使用

### 配置 API 端点

支持任何兼容 OpenAI Chat Completions 协议的 API 服务。

右键扩展图标 →「选项」，配置以下字段：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| API Key | API 访问密钥 | — |
| API Base URL | 请求端点 | `https://api.deepseek.com/v1` |

也可使用 OpenAI（`https://api.openai.com/v1`）、Ollama、vLLM 等其他服务。

### 翻译

点击扩展图标 →「翻译本页」。进度条实时反馈。

### 显示模式

| 模式 | 行为 |
|------|------|
| 双语对照 | 原文保留，译文插入下方 |
| 仅译文 | 隐藏原文 |
| 仅原文 | 恢复原始页面 |

通过弹出面板或页面右下角悬浮按钮切换。

### 增量内容

页面滚动加载或路由切换产生的新内容自动检测并翻译。

### 还原

点击「清除翻译」或刷新页面。

## 翻译保护规则

| 内容类型 | 策略 |
|----------|------|
| `<pre><code>` 代码块 | 整棵子树跳过 |
| 行内 `<code>` | 占位符保留，译文中原样呈现 |
| `<a>` 超链接 | 占位符 + `cloneNode(true)` 重建，结构完整 |
| 技术术语 | React, API, Docker 等保留原文 |

## 适用场景

- 开源项目文档
- API 参考与规范
- 技术教程与开发者指南
- 技术博客与白皮书

不适用于社交媒体、新闻资讯等非技术类内容。

## FAQ

**单页翻译耗时？** 通常 3–10 秒。已缓存页面即时呈现。

**是否影响页面功能？** 否。仅通过 `appendChild` 与 `createTextNode` 追加节点，不使用 `innerHTML`，原始 DOM 不做任何修改。

**成本？** 取决于 API 服务商计费标准。以 DeepSeek `deepseek-chat` 为例，单页约消耗数千 token，成本低于 0.01 元。新用户有免费额度。

**支持哪些 API？** 所有兼容 OpenAI Chat Completions 协议的服务，包括 DeepSeek、OpenAI、Ollama、vLLM、LM Studio 等。

## 隐私

- API 密钥存储于 `chrome.storage.local`，仅本地可用
- 翻译请求由浏览器直达你配置的 API 端点，不经过中间服务器
- 不采集任何使用数据
